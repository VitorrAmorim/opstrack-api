#Aula 1 - Início do Projeto

- Criei a pasta do projeto e um ambiente virtual Python isolado
- Instalei o Flask e gerei o `requirements.txt` com `pip freeze`
- Criei o `app.py` com uma rota HTTP (`GET /`) retornando uma mensagem de status
- Testei a aplicação localmente e confirmei que funcionava
- Inicializei o Git, criei o `.gitignore` (ignorando `venv/`, `__pycache__/`, `*.pyc`) e fiz o primeiro commit
- Publiquei o repositório no GitHub
